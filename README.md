## 📖 Tentang Portal
Aplikasi **PPID Kemenag Kota Parepare** adalah platform digital yang dirancang untuk mewujudkan keterbukaan informasi publik sesuai dengan amanat Undang-Undang No. 14 Tahun 2008. Melalui portal ini, masyarakat dapat mengakses dokumen, laporan kinerja, dan berbagai informasi penting lainnya secara cepat, mudah, dan transparan.

Kami berkomitmen untuk mendukung terciptanya tata kelola pemerintahan yang baik (*Good Governance*) dan Zona Integritas di lingkungan Kantor Kementerian Agama Kota Parepare.

## ✨ Fitur Unggulan
- 🔍 **Pencarian Dokumen Canggih:** Temukan informasi secara instan dengan fitur pencarian yang responsif.
- 📊 **Dashboard Statistik Real-Time:** Visualisasi distribusi dokumen publik (Berkala, Setiap Saat, Serta Merta, Dikecualikan).
- 📂 **Manajemen Dokumen Terstruktur:** Filter informasi berdasarkan kategori, tahun, dan tipe file (PDF, Excel, dll).
- 🌓 **Antarmuka Premium (Dark/Light):** Desain modern dengan dukungan mode gelap dan terang yang nyaman di mata.
- 📱 **Desain Ultra-Responsif:** Pengalaman pengguna yang mulus di perangkat mobile, tablet, maupun desktop.
- 🎫 **Pelacakan Status Permohonan:** Pantau progres pengajuan informasi Anda hanya dengan ID Tiket.
- 💬 **Integrasi Multi-Channel:** Ajukan permohonan melalui formulir online, unduhan PDF, atau konsultasi via WhatsApp.
- 🤖 **AI Assistant (Gemini):** Integrasi kecerdasan buatan untuk membantu pencarian dan tanya jawab informasi.

## 🛠️ Arsitektur Teknologi
Portal ini dibangun dengan teknologi mutakhir untuk performa dan keamanan optimal:

- **Framework:** [Next.js 15](https://nextjs.org/) (App Router)
- **Library UI:** [React 19](https://react.dev/)
- **Styling:** [Tailwind CSS 4](https://tailwindcss.com/) (Modern Utilities)
- **Animasi:** [Framer Motion](https://www.framer.com/motion/) (Smooth Transitions)
- **Ikonografi:** [Lucide React](https://lucide.dev/)
- **Artificial Intelligence:** [Google Gemini API](https://ai.google.dev/) (Advanced LLM)

## 🚀 Panduan Memulai (Lokal)

### 📋 Prasyarat
- **Node.js:** Versi 18.x atau lebih baru
- **NPM** atau **Yarn** atau **PNPM**

### 🛠️ Langkah-langkah Instalasi

1. **Clone Repository:**
   ```bash
   git clone https://github.com/syarfandi/ppidparepare.git
   cd ppidparepare
   ```

2. **Instal Dependensi:**
   ```bash
   npm install
   ```

3. **Konfigurasi Lingkungan (.env):**
   Salin file `.env.example` menjadi `.env.local` dan isi API Key Anda.
   ```bash
   cp .env.example .env.local
   ```
   Edit `.env.local`:
   ```env
   GEMINI_API_KEY="AIzaSyA..."
   ```

4. **Jalankan Mode Pengembangan:**
   ```bash
   npm run dev
   ```
   Buka portal lokal di [http://localhost:3000](http://localhost:3000) atau akses langsung portal produksi resmi di [https://ppidparepare.vercel.app/](https://ppidparepare.vercel.app/).
